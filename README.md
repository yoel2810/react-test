🎂 Birthday Surprise Website

A cute and interactive birthday website made with React for the most special person in my life ❤️

This project is a personalized birthday experience filled with animations, memories, music, love notes, and little surprises.

✨ Features
💖 Animated landing page
📸 Photo gallery / memories section
💌 Love letters and birthday messages
🎵 Background music support
🎂 Countdown timer
🎁 Hidden surprise interactions
🌸 Smooth transitions and modern UI
📱 Mobile responsive
🛠️ Built With
⚛️ React
🎨 MUI
✨ Framer Motion
🎵 HTML5 Audio API
